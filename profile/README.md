# Isanin Studio

🎬 Создание видео: сценарии, озвучка, запись, монтаж и аналитика.

Инструменты для подготовки видеороликов — от первой идеи до готового материала и анализа публикаций.

## 🧭 Направления

| Направление | Назначение |
|---|---|
| 📝 Сценарии | Идеи, тексты озвучки, раскадровки и статусы подготовки роликов. |
| 🎙️ Озвучка | Локальный синтез речи по тексту с использованием образца голоса. |
| 🎥 Запись | Маски и вспомогательные материалы для записи в OBS. |
| ✂️ Монтаж и аналитика | Сборка видео по плану, сведения о канале и публичная статистика YouTube. |

## 📂 Открытые проекты

| Проект | Назначение | Что внутри |
|---|---|---|
| [voice-clone-ai](https://github.com/isanin-studio/voice-clone-ai) | Синтез речи своим голосом | Образец голоса и текст → звуковой файл. |
| [obs-assets](https://github.com/isanin-studio/obs-assets) | Материалы для OBS | Маски и материалы для оформления записи. |

## 🔄 Как устроена работа

1. Сформулировать идею ролика и подготовить сценарий.
2. Записать голос или создать озвучку по тексту.
3. Подготовить запись экрана и другие материалы.
4. Собрать ролик по плану, проверить звук и изображение.
5. После публикации собрать доступную статистику YouTube.

## 🚀 С чего начать

Для озвучки откройте voice-clone-ai, для материалов записи — obs-assets. Сценарии и инструменты аналитики доступны участникам организации.

## 📌 О материалах

Текст сценария, звуковые файлы и материалы записи относятся к разным этапам работы. Команды запуска и требования к каждому инструменту находятся в его репозитории.

Часть проектов доступна только участникам организации. Инструкции запуска,
требования и ограничения проверяйте в README выбранного репозитория.
